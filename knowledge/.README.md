# Knowledge inbox

Wrzucaj tutaj pliki `.txt`, `.md`, `.markdown`, `.rst`, `.log`, `.vtt` lub `.srt`.
Katalogi podrzędne są obsługiwane. Aplikacja skanuje katalog cyklicznie, aktualizuje zmienione
pliki i usuwa z aktywnego indeksu pliki skasowane z katalogu.

Data używana do premiowania nowej wiedzy jest wybierana w kolejności:

1. `effective_at` lub `date` w YAML front matter,
2. data `YYYY-MM-DD` w nazwie pliku,
3. data modyfikacji pliku.

Przykład front matter:

```markdown
---
title: Checkout discovery
project: checkout
effective_at: 2026-07-31
tags: [payments, discovery]
---

Treść spotkania...
```
